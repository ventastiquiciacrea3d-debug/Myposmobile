PASO 1: ABRE WORDPRESS
   → Ve a: https://tcrea3d.com/wp-admin
   → Inicia sesión

PASO 2: VE A PLUGINS
   → En el menú izquierdo, clic en: Plugins
   → Luego clic en: Añadir nuevo

PASO 3: SUBE EL ARCHIVO
   → Arriba de la página, clic en: "Subir plugin"
   → Clic en: "Elegir archivo"
   → Selecciona: my-pos-barcode-mobil-plugging.zip
   → Clic en: "Instalar ahora"

PASO 4: REEMPLAZA EL PLUGIN VIEJO
   → WordPress preguntará: "¿Reemplazar el plugin actual?"
   → Clic en: "Sí" o "Reemplazar plugin actual"
   → Espera 10-30 segundos

PASO 5: ACTIVA EL PLUGIN
   → Cuando termine, clic en: "Activar plugin"
   → ¡LISTO!

🆘 PROBLEMAS COMUNES:

❌ "No veo el botón Subir plugin"
   → Tu usuario necesita permisos de Administrador

   → Luego ELIMINA el plugin viejo
   → Ahora sube el nuevo

❌ "Archivo no válido"
   → Asegúrate de subir el archivo .ZIP
   → NO descomprimas el archivo antes de subirlo
